| Код | Требования                         | Комментарий  |
|-----|------------------------------------|--------------|
| F   | Функциональные (Functionality)     |              |
| F1  | Новый клиент видит список доступных депозитов с актуальными ставками на сайте                               |              |
| F2  | Клиент может подать заявку на депозит, оставив номер телефона и Ф. И. О                               |              |
| F3  | Менеджер кол-центра изучает заявку и предлагает особые условия                               |              |
| F4  | Новый клиент приглашается в отделение банка для подтверждения документов                                |              |
| F5  | Сотрудник кредитного отдела может считать ставку депозита в системе АБС                               |  Сейчас только в файле Excel            |
| F6  | Сотрудник бэк-офис может считать персональную ставку депозита на основе кредитного риска в системе АБС                               |  Сейчас только в файле Excel            |
| F7  | В интернет-банке авторизованный клиент видит персонализированные ставки и может подавать заявки на открытие депозита с подтверждением через СМС-код                                |              |
| F8  | Клиент интернет-банка получает уведомления об открытии депозита по СМС или push                               |              |
| U   | Удобство использования (Usability) |              |
| U1  | Интерфейс должен соответствовать дизайну банка                              |              |
| U2  | Быстрый отклик на операции                              | Меньше 1 секунды            |
| R   | Надёжность (Reliability)           |              |
| R1  | Шифрование чувствительной информации при передаче данных                               |              |
| R2  | Все сервисы должны работать 24/7 и быть доступны в 99,9% случаев                               |              |
| R3  | Избежать прямой работы интернет-банка с API АБС для повышения надежности                             |              |
| R4  | Возможность переключения на резервный ЦОД в случае сбоя                              | Разработать Failover стратегию           |
| P   | Производительность (Performance)   |              |
| P1  | Оптимизация загрузки справочных данных из АБС                             | Не более 1 секунды             |
| P2  | Горизонтальное масштабирование и распределение запросов между серверами и ЦОДами для новых сервисов                               |            |
| P3  | Вертикальное масштабирование АБС                              | Из-за ограничений базы данных          |
| S   | Поддерживаемость (Supportability)  |              |
| S1  | Разработка микросервисов по депозитам в рамках MVP                              | Первый шаг для распила монолита и миграции с легаси-стека             |
| S2  | Разработка документации для дальнейшего расширения системы                               | Важный фактор для дальнейшего распиал монолита АБС            |
| S3  | Использование существующих технологий (MS SQL, Oracle) для интеграции новых решений с имеющимися системами                              |              |
| S4  | Обучение сотрудников новым технологиям          | Например, Kafka            |
| +R  | + Ограничения (Restrictions)       |              |
| +R1 | Защита данных при передаче в интернет-банке с помощью механизма шифрования                               | Банковская тайна, регуляторные риски            |
| +R2 | Поддержка функционала SMS в ядре системы с минимальными доработками со стороны подрядчика                               | Возможны Vendor-lock риски            |
| +R3 | АБС масштабируется только вертикально | Учитывать при расчёте нагрузки |
| +R4 | Приоритет в использовании существующих технологии в компании (MS SQL, Oracle) | Учитывать лицензионные ограничения |
| +R5 | Избегать прямой работы интернет-банка с API АБС    | Можно использовать брокер сообщений (kafka), если система АБС сможет ее поддерживать                                                                                                    |
