### <a name="_qmphm5d6rvi3"></a>**Решение**
Для решения задачи решено создать сервис ставок (SpringBoot, Oracle), который будет парсить актуальные ставки, полученные через корпорутивную почту. Для предоставления актуальной информации по ставкам для сотрудников бэк-офиса разработаем форму просмотра ставок, для внутреннего колл-центра модернизируем CRM, которая будет получать ставки по API у сервиса ставок, а для внешнего колл-центра будет вызываться процедура экспорта ставок в файд CSV по протоколу SFTP на сервер внешней организации. Это позволит уже в MVP сделать шаг в сторону исключения использования почты.

### <a name="_bjrr7veeh80c"></a>**Альтернативы**
Можно было бы реализовать прямую запись данных в CRM DB, но этот подход нарушает принципы построения микросервисов.
